# eat-what-you-have — evolutionary scorecard

| Test | Score | Reasoning |
|---|---|---|
| **Capability transfer** | Pass | Teaches the "look first" pattern. Why-these reasoning surfaces what was used vs cut. User learns to scan their own kitchen. |
| **Reach extension** | Pass | Extends cooking confidence — user attempts meals they wouldn't have thought of from a familiar list. |
| **Teaching surface** | Pass | "What's about to expire" + reasoning forces the gadget to show its filtering, not just deliver a recipe. |
| **Long-run effect** | Conditional | If user lists items without opening the fridge, the gadget hallucinates and confidence calibrates wrong. Requires user honesty to work. |
| **Friction respect** | Pass | Removes wasteful friction (decision fatigue, plan-from-blank). Preserves productive friction (the cooking itself). |

**Score: 4 hard passes + 1 conditional.** Qualifies.

## Failure mode to refuse

If user starts inventing items they don't have because the suggested meal looks good, the gadget has become a recipe app. Refuse: only meals from listed items, period.

## v0.2 idea

Optional expiry-date input per item. Switches "I'm assuming X spoils first" to actually-known order.
