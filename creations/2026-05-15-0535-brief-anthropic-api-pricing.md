## What you need to know

Anthropic API bills per token — input cheaper than output. Rough current shape (verify before budgeting):

- **Opus 4.7** — ~$15 / Mtok input, ~$75 / Mtok output (top tier)
- **Sonnet 4.6** — ~$3 / $15 (very capable, much cheaper)
- **Haiku 4.5** — ~$1 / $5 (cheapest, still strong)

A typical `brief` call (~1k input, ~2k output) on Opus is ~$0.17. ~600 calls/month = ~$100. Sonnet would be ~$0.04 each.

Rate limits scale with **usage tier**. New accounts = tier 1 (low: ~5 RPM, ~20k input tok/min). Spend ~$5 → tier 2. Up to tier 4 with much higher limits. Tier upgrades auto-trigger on spend thresholds.

**Prompt caching** = ~10× discount on identical leading prefixes ≥1024 tokens. Your `prompt.md` is your system text; if you push the same template across many calls, this matters a lot. Cached input billed at ~0.1× normal.

Cost-control levers worth knowing: `max_tokens` caps the bill per call (already set in `brief.ps1`); model routing — Haiku for routine, Opus only for hard.
